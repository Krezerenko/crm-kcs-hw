Заголовок Issue:
[KCS] 429 Too Many Requests при синхронизации контактов с API почтового сервиса

Тело (вставляется в шаблон):

## Проблема
При массовой синхронизации клиентов CRM с API почтового сервиса (рассылки) часть запросов падает с ошибкой `429 Too Many Requests`, контакты синхронизируются не полностью.

## Причина
API ограничивает частоту запросов (rate limit), а модуль синхронизации отправляет запросы без пауз и не учитывает заголовок `Retry-After`.

## Решение
1. Отправлять контакты пакетами (batch-эндпоинт, до 100 контактов за запрос).
2. При ответе 429 ждать время из заголовка `Retry-After`, затем повторять запрос.
3. Ограничить число повторов (3) и логировать неудачные контакты.
